云母 Kirara 2.4.0 新增离线智能搜索、PTD Cookie 同步，并优化发布构建流程。

- 站点和任务页面支持离线智能搜索，结合内置目录、语义匹配和自定义名称绑定查找站点。
- 站点管理支持手动导入 PTD 备份中的 Cookie，也可启用 WebDAV 接收 PTD 定时推送，实现 Cookie 自动同步。
- 站点操作增加手动同步账号统计数据，并改善站点展示和 NexusPHP 兼容性。
- 优化 Rust、桌面打包工具和 Docker 构建缓存，减少安装包上传时的重复压缩。
- 搜索检查独立运行，不再阻塞日常 snapshot 打包；手动指定版本发布仍需通过完整搜索检查。

升级时保留原数据目录。Docker 正式版：`ghcr.io/imythu/kirara:2.4.0` / `latest`；测试渠道：`latest-beta`。
