云母 Kirara 2.1.0 补齐桌面应用托盘与后台常驻功能。

### 桌面应用

- 关闭主窗口后隐藏到 Windows 系统托盘或 macOS 菜单栏，自动扫描、下载队列和定时任务继续运行。
- 图标菜单提供“打开主窗口”和“退出”；Windows 单击托盘图标即可恢复主窗口。
- 再次启动应用会恢复原有窗口，macOS 也支持通过 Dock 唤醒。
- 明确选择“退出”时停止后台服务，并清理正在进行的日志订阅；补齐 macOS 原生退出时的服务清理。

### 安装与升级

从本页附件下载对应平台的安装包或压缩包，并使用 `SHA256SUMS.txt` 校验：

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows x64 | `kirara-2.1.0-x86_64-pc-windows-msvc-setup.exe` | 运行安装程序，从开始菜单打开 Kirara |
| macOS Apple Silicon | `kirara-2.1.0-aarch64-apple-darwin.dmg` | 将 Kirara 拖入“应用程序”后打开 |
| Linux amd64 | `kirara-2.1.0-x86_64-unknown-linux-musl.tar.gz` | 解压后运行 `./kirara` |
| Linux arm64 | `kirara-2.1.0-aarch64-unknown-linux-musl.tar.gz` | 解压后运行 `./kirara` |

当前 Windows 安装包未配置开发者签名；macOS 使用临时签名，尚未经过 Apple 公证，首次打开可能出现系统的发布者验证提示。macOS 可参考 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

从 2.0.0 升级时，先退出旧应用，再安装新版，原有应用数据会继续使用。新版关闭窗口后会继续在后台运行，需要停止服务时请从托盘或菜单栏图标菜单选择“退出”。

从 1.x 命令行版本升级到桌面版前，请停止旧程序并备份整个数据目录，再按[桌面版数据迁移说明](https://github.com/imythu/kirara/blob/v2.1.0/README.md#桌面版数据迁移)将旧数据复制到应用数据目录。已有 `kirara.db` 和 `rflush.db` 均可继续使用，无需转换数据库格式。

Linux 与 Docker 延续现有部署方式，默认 Web 访问地址为 `http://127.0.0.1:3000`，启动参数和数据目录配置保持兼容。

Docker 镜像：`ghcr.io/imythu/kirara:2.1.0`，稳定渠道：`ghcr.io/imythu/kirara:latest`，均支持 Linux amd64 / arm64。自动 snapshot 继续提供 Linux amd64 压缩包和 `latest-beta` 镜像。
