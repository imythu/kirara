云母 Kirara 2.4.6 新增 U2 视觉识别签到与视觉 LLM 配置。

- 适配 U2 签到，自动提取图片与候选作品，通过视觉模型识别后提交；无法确定作品时不提交答案。
- 在「配置签到工具」中新增视觉 LLM 配置，支持 Claude、OpenAI 兼容和 OpenAI Responses 接口。
- 视觉模型 API Key 不在设置接口中回传，支持留空保留和主动清除。
- 完善 Lightpanda 代理连接与签到日志，展示识别理由并保留近期运行日志。
- 新增统一开发服务管理脚本，Web 开发端口统一为 1234。

升级时保留原数据目录；使用 U2 签到前请配置 Lightpanda 和视觉 LLM。Docker 正式版：`ghcr.io/imythu/kirara:2.4.6` / `latest`。
