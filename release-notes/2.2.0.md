云母 Kirara 2.2.0 新增 Browserless 图片验证码签到，以及已签到提示识别配置。

### 自动签到

- 选择“图片验证码签到”后，可配置签到路径、验证码图片、输入框和签到按钮的 Selector，由 Browserless 识别并填写验证码。
- 内置皇后和包子站的图片验证码预设。皇后默认路径为 `/plugin_sign-in.php`，其他站点默认 `/attendance.php`；无预设站点的选择器留空供填写。
- 图片验证码预设提供与 CF 签到一致的修改提醒。
- CF 和图片验证码签到均可配置已签到／重复签到提示文字，每行一条。验证前后命中任意一条时，跳过后续验证和点击；留空不启用提前跳过。
- 支持皇后的 JSON 签到成功响应，并避免将仍有验证码表单的页面或签到日历说明误判为完成。

### 升级

退出旧程序后安装新版，保留原数据目录。新配置字段在启动时自动迁移。

已有包子等签到任务可编辑并选择“图片验证码签到”，检查预设后保存。使用此方式需要配置公共 Browserless 地址和 Token。

Docker 镜像：`ghcr.io/imythu/kirara:2.2.0`；稳定渠道：`ghcr.io/imythu/kirara:latest`。
