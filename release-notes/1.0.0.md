云母 Kirara 首个正式版本。

### 影视与 PT 管理

- 电影、电视剧与动漫订阅，按季集或动画绝对集跟进更新。
- 多站资源聚合搜索、质量筛选与 qBittorrent 下载队列。
- PT 站点与下载器管理、刷流任务、自动签到、标签规则及数据统计。
- 可查询的扫描结果、匹配原因、下载状态和系统日志。

### 云母主题界面

- 奶油白工作区、炭黑导航与朱红操作色。
- 云母猫又标志和双尾空状态图。
- 统一表单、表格及图表风格，适配桌面、平板和手机。
- 改善移动导航、键盘焦点和表单操作体验。

### 从旧项目升级

项目由 `rflush` 迁移至 `kirara`，中文名继续使用“云母”。已有数据目录可继续使用，无需手动更名数据库；启动脚本、镜像地址和环境变量需按[迁移指南](https://github.com/imythu/kirara/blob/v1.0.0/doc/migration-from-rflush.md)更新。

升级前请停止旧服务并备份完整数据目录。

### 安装

下载适合系统架构的压缩包并校验 `SHA256SUMS.txt`，解压后运行 `kirara`（Windows 使用 `kirara.exe`）。默认访问 `http://127.0.0.1:3000`。

Docker 镜像：`ghcr.io/imythu/kirara:1.0.0`，稳定渠道：`ghcr.io/imythu/kirara:latest`。
