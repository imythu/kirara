云母 Kirara 2.5.0 对齐 PT-depiler 站点适配能力：数据驱动站点规则、KeepFRDS JSON 用户统计、Unit3D 用户统计与种子搜索。

### 站点适配

- 新增声明式站点规则表 `SITE_RULES`（`src/site/rules.rs`），NexusPHP 通用解析支持按站点覆盖字段标签、CSS 选择器、魔力页路径、AJAX Referer／禁用。
- 已内置 Audiences（爆米花／顶栏指标／AJAX Referer）、BYRBT（`mybonus.php?show=seed`）、U2（UCoin／`mprecent.php`）、KeepFRDS、OurBits、HDChina、HDSky、CHDBits 等规则。
- KeepFRDS：优先 `/api/userdetails.php` JSON 获取核心用户数据，资料页 `#perBonus` 补时魔；跳过已废弃的种子列表 AJAX。
- 新增 PT-depiler definition 规则生成器 `tools/gen_ptd_site_rules.py`，可从站点定义抽取选择器与接口路径草稿，合并前需 review。流程见 `doc/ptd-site-rules.md`。

### Unit3D

- 站点类型新增 `unit3d`，支持用户统计（ratio-bar 与标签回退）与 Cookie 认证。
- 新增 Unit3D 种子搜索 Indexer：`/torrents/?name=` 列表解析与 `/torrents/download/{id}` 下载。
- 站点目录预设增加 Blutopia、Aither、HUNO、FearNoPeer、ShareIsland。

### 其他

- README 增加对 PT-depiler（MIT）的致谢与文档链接。
- 站点适配、规则同步与排错说明沉淀在 [doc/ptd-site-rules.md](doc/ptd-site-rules.md)。

### 升级

退出旧程序后安装新版，保留原数据目录。Unit3D 站点请在站点管理中将类型选为 `unit3d`，并配置 Cookie（不支持仅 API Key）。Gazelle 仍仅支持用户统计，尚未支持搜索。

Docker 镜像：`ghcr.io/imythu/kirara:2.5.0`；稳定渠道：`ghcr.io/imythu/kirara:latest`。
