云母 Kirara 2.3.3 简化自动签到配置。

- 皇后、包子、ds 和 iloli 选择站点即可自动匹配固定签到方式，无需手动选择浏览器或填写技术参数。
- 未适配站点可选择打开页面、CF 页面挑战、CF Turnstile 或通用图片验证码签到；通用验证码仅保留最初五项配置。
- 签到器独立存放并共用统一接口。包子复用通用验证码签到，皇后扩展为等待表单响应后判断结果。
- 已保存任务执行时自动采用对应签到器，不需要恢复预设；旧版自定义提交方式、结果规则及等待参数由签到器固定配置替代。
- 缺少对应云浏览器连接信息时明确提示，并提供配置入口。配置页面补充云浏览器用途、服务选择与账号注册说明。

升级时保留原数据目录。Docker 正式版：`ghcr.io/imythu/kirara:2.3.3` / `latest`；测试渠道：`latest-beta`。
