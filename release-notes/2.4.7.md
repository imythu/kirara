云母 Kirara 2.4.7 新增「求药 / 发药」页面，支持按站点与 UID 核验公开资料。

- 新增求药发药页：出示方勾选站点导出「站点名|UID」与预注册信息；核验方可粘贴管道格式、资料链接或圈内俗称，解析后自动逐条查询。
- 公共用户资料抓取：NexusPHP / Gazelle / M-Team 统一返回用户名、UID、邮箱、上传下载、本地分享率、入站时间与做种数/做种体积；失败原因区分请求失败、被拦截与解析失败。
- 站点统计在首次遇到邮箱为空时补充抓取本人邮箱；已保存非空邮箱后不再重复请求，失败不影响统计落库。
- 复制求药信息前先弹出预览；站名使用站点管理中的名称，并汇总所选站点上传、下载与做种。
- 邮箱通过 `mailto:` 或 Cloudflare 混淆从公开资料页解析，不默认抓取账户机密设置。

升级时保留原数据目录。Docker 正式版：`ghcr.io/imythu/kirara:2.4.7` / `latest`。
