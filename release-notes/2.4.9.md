云母 Kirara 2.4.9 新增通用定时任务与完整的 HTTP 请求配置面板。

- 新增「自动任务 → 定时任务」，默认使用指定间隔，也可配置高级五字段 CRON 表达式、固定时区及未来三次执行时间。
- 支持 HTTP 方法、查询参数、请求头，无认证、Bearer、Basic、API Key（Header/Query）及 Cookie。可以查看最终认证信息、主动载入已保存配置和预览最终请求。
- Cookie 输入框内置悬浮站点选择器，支持搜索并复制已有站点的当前 Cookie，填入后仍可编辑。
- 请求体支持 JSON、URL 编码表单、multipart 文本和文件、纯文本、XML、HTML、二进制及自定义格式。上传文件随任务保存，正文或表单内容与文件合计最大 256 KiB。
- 支持 HTTP 客户端或 Browserless 浏览器发送。HTTP 模式可使用全局代理；浏览器模式可单独选择连接 Browserless 时使用全局代理，浏览器到站点的出口由浏览器服务配置决定。Browserless 需支持 /function API，复用自动签到工具中的地址与 Token。
- 支持启用/暂停、立即执行、最近 100 条记录、状态码和耗时。任务与记录持久化，避免同任务重叠执行，重启后保留执行状态；失败不自动重试。

升级时保留原数据目录。已有业务任务不受影响。Docker 正式版：`ghcr.io/imythu/kirara:2.4.9` / `latest`。
