云母 Kirara 2.3.1 增加可配置的签到提交方式与结果识别。

- Browserless 支持点击按钮、原生表单提交和同源 AJAX 提交。AJAX 会等待响应后判断结果。
- 支持文字、可见元素和 JSON 字段匹配；可配置成功、已签到与失败规则，JSON 严格区分字符串、布尔值、数字和 null。
- 失败规则优先于已签到与成功；提交前识别已签到可跳过验证和提交。配置规则后未命中会报告结果未知。
- 皇后预设使用 AJAX，按 JSON `/state` 字符串 `success` 或 `false` 识别成功；包子提供页面文字规则。站点差异保存在预设中。
- 兼容原有配置。已有任务可进入“提交方式与结果识别”，点击“恢复本站预设”并保存，以应用新版默认值；此操作会重置该任务的浏览器签到参数。

Docker 镜像：`ghcr.io/imythu/kirara:2.3.1`；稳定渠道：`ghcr.io/imythu/kirara:latest`。
