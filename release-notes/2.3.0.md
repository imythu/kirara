云母 Kirara 2.3.0 完善自动签到站点预设和浏览器配置指引。

### 自动签到预设

- 新建任务或切换站点时，皇后、包子自动选择 Browserless 和图片验证码签到，并填入对应路径与选择器。
- ds 自动选择 Browserless、CF 签到和页面挑战；iloli 自动选择 Browserless、CF 签到和 Turnstile。
- 补齐图片验证码站点的已签到识别默认提示；包子使用再次访问时显示的“签到成功”。皇后当前签到入口在已签到后仍显示验证码，界面明确提示默认关键词不能保证提前跳过。
- 打开已保存的 Browserless 签到任务时保留用户配置。

### 浏览器配置

- 提供 Browserless 默认云端地址；Lightpanda 默认地址随所选区域切换，并自动带入 Token。
- 增加官方注册、控制台入口，以及创建或复制 API Key／Token 后保存测试的引导。
- 保留已有自定义服务地址。

### 升级

退出旧程序后安装新版，保留原数据目录。已有任务可在编辑界面按需调整配置。

Docker 镜像：`ghcr.io/imythu/kirara:2.3.0`；稳定渠道：`ghcr.io/imythu/kirara:latest`。
