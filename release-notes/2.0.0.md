云母 Kirara 2.0.0 为 Windows 和 macOS 带来桌面应用。

### 桌面应用

- Windows x64 提供安装程序，macOS Apple Silicon 提供 DMG 安装映像。
- 启动后直接进入云母管理界面，无需使用命令行或单独打开浏览器。
- 复用现有影视订阅、资源搜索、下载队列、刷流任务和站点管理功能。
- 配置和数据库保存到系统应用数据目录，退出应用时停止后台任务。

### 安装与升级

从本页附件下载对应平台的安装包或压缩包，并使用 `SHA256SUMS.txt` 校验：

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows x64 | `kirara-2.0.0-x86_64-pc-windows-msvc-setup.exe` | 运行安装程序，从开始菜单打开 Kirara |
| macOS Apple Silicon | `kirara-2.0.0-aarch64-apple-darwin.dmg` | 将 Kirara 拖入“应用程序”后打开 |
| Linux amd64 | `kirara-2.0.0-x86_64-unknown-linux-musl.tar.gz` | 解压后运行 `./kirara` |
| Linux arm64 | `kirara-2.0.0-aarch64-unknown-linux-musl.tar.gz` | 解压后运行 `./kirara` |

当前 Windows 安装包未配置开发者签名；macOS 使用临时签名，尚未经过 Apple 公证，首次打开可能出现系统的发布者验证提示。macOS 可参考 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

从 1.x 命令行版本升级到桌面版前，请停止旧程序并备份整个数据目录，再按[桌面版数据迁移说明](https://github.com/imythu/kirara/blob/v2.0.0/README.md#桌面版数据迁移)将旧数据复制到应用数据目录。已有 `kirara.db` 和 `rflush.db` 均可继续使用，无需转换数据库格式。

Linux 与 Docker 延续现有部署方式，默认 Web 访问地址为 `http://127.0.0.1:3000`，启动参数和数据目录配置保持兼容。

Docker 镜像：`ghcr.io/imythu/kirara:2.0.0`，稳定渠道：`ghcr.io/imythu/kirara:latest`，均支持 Linux amd64 / arm64。自动 snapshot 继续提供 Linux amd64 压缩包和 `latest-beta` 镜像。
