# 自动签到交互 Demo

启动：`node demos/sign-in/server.cjs`

预览：http://localhost:31235/ ，直接展开批量创建：http://localhost:31235/#batch 。服务监听 `0.0.0.0:31235`。

纯 HTML、CSS、原生 JavaScript，无需构建。示例站点使用 `.example` 域名；数据仅保存在页面内存，刷新重置，不调用业务接口。

可体验：单个新增、批量创建、站点搜索、全选搜索结果内可创建站点、重复任务跳过、不可用原因、执行间隔、暂停/启用、模拟执行与执行记录。导航侧栏只提供现有产品的视觉上下文。

设计继承项目暖米色、深色导航与朱红操作按钮。创建面板采用页内展开，桌面双栏、手机纵向排列；可选站点优先，站点列表超过 350px 可滚动。宽任务表支持横向滚动。

已通过浏览器交互验证和 1440px / 390px 截图检查。独立于正式前端与后端实现。
